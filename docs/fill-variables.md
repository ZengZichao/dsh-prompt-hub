# 填写提示词变量

插入提示词时，把正文里的 `{{名称}}` 换成具体内容。变量在正文里写作 `{{名称}}`；花括号内侧允许空格，`{{ 名称 }}` 同样有效。

<!-- 截图位：填写变量对话框，每个变量一个输入框，底部是取消和插入。alt：填写变量对话框，按变量名列出输入框，下面一行说明“留空则保留占位符”，底部是取消和插入按钮。 -->

1. 在输入框点击 **插入提示词**。
2. 点击一条含变量的提示词。
3. 在 **填写变量** 对话框里，为每个变量填一个值。
4. 点击 **插入**。

**结果：** 输入框里得到替换后的正文；没填值的变量保留原来的 `{{名称}}` 占位符。

> 提示：对话框底部的说明是“留空则保留占位符”。清理占位符要在插入后手动改，或者回到面板 **编辑** 原文。

> 提示：同名变量只出现一个输入框；输入顺序按变量在正文中第一次出现的顺序。填写的值会去掉首尾空格。

> 提示：变量只在插入时处理，面板列表和编辑页不会提示变量名。
