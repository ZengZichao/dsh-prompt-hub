# 从输入框插入提示词

把提示词写进当前对话的草稿而不发送，适合在写消息前套用一段固定指令。

<!-- 截图位：输入框选择器，含搜索框、管理提示词按钮、分类筛选按钮和提示词列表。alt：输入框上方弹出的选择器，顶部是搜索框和管理提示词，下面是全部、未分类等分类按钮与提示词条目。 -->

1. 在对话输入框左侧的工具行点击 **插入提示词**（对话气泡图标）。
2. 在选择器顶部用 **搜索提示词** 过滤，或点分类按钮（**全部**、**未分类**、各分类名）切换范围。
3. 点击一条提示词。
4. 正文进入输入框。已有草稿时，按当前的 **插入方式** 处理：
   - **追加**（默认）：在草稿末尾空两行后追加。
   - **替换**：用提示词正文覆盖整段草稿。
5. 补充你的问题后发送。

**结果：** 输入框里是提示词正文，消息不会自动发出。

> 提示：提示词里含 `{{变量}}` 时，会先打开 **填写变量** 对话框，见 [填写提示词变量](fill-variables.md)。

> 提示：点选择器里的 **管理提示词** 会跳到主面板并关闭选择器。按 Esc 或点选择器外面也能关闭。

> 提示：选择器底部显示“共 N 条”，超出显示上限时改为“显示 X / Y”；显示条数在 **设置** 里调整。
