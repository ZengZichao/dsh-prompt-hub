# 置顶常用提示词

把最常用的提示词固定在列表顶部，也让它在输入框选择器里排在最前。

1. 打开 **提示词中心**，选中提示词所在的分类（或 **全部**）。
2. 找到目标提示词，点击标题左侧的图钉按钮。悬停提示为 **置顶**。
3. 图钉高亮，提示词移到列表顶部。
4. 再次点击图钉（此时悬停提示为 **取消置顶**）恢复普通排序。

**结果：** 面板提示“已保存”，该提示词排在同分类其他提示词之前；置顶状态对 AI 工具同样可见。

> 提示：排序规则是置顶优先，其次按最近更新。置顶本身不改变提示词的更新时间。
