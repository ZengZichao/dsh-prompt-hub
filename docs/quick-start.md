# 安装并插入第一条提示词

这篇带你把 dsh-prompt-hub 装好、存下第一条提示词，并把它插入对话输入框。开始前你需要：DeepSeek Harness 0.2.2-rc.3 或更高的 0.2.x 版本，Node.js 24.9 及以上，以及本插件目录的访问权限。

1. 在 DeepSeek Harness 的插件管理器中，从本插件目录安装 bundle（安装接口为 `install_bundle`）。插件不发布到 npm。
2. 确认 dsh-prompt-hub 已启用，然后在左侧面板列表找到 **提示词中心**（英文界面 **Prompt hub**）。
   <!-- 截图位：左侧面板列表中的「提示词中心」入口（对话气泡图标）。alt：左侧面板列表里高亮的“提示词中心”按钮。 -->
3. 点击 **提示词中心**。面板打开：上方是 **搜索提示词** 和 **新建提示词**，左侧是 **分类** 栏，右侧是提示词列表。
4. 点击 **新建提示词**。
5. 在 **标题** 里写一个以后能认出来的名字，例如“代码审查”。
6. 在 **内容** 里写提示词正文。以后要替换的词写成 `{{语言}}` 这样的变量。
7. 点击 **保存**。
   > 提示：面板提示“已保存”，新提示词出现在列表顶部。若已有分类，新提示词默认归入分类列表里的第一个分类；可在 **分类** 下拉里改成 **未分类** 或其他分类。
8. 回到对话，在输入框左侧的工具行点击 **插入提示词**（对话气泡图标）。
   <!-- 截图位：输入框工具行最左侧的「插入提示词」按钮，以及点开后弹出的选择器。alt：输入框左侧的对话气泡按钮，下方弹出含搜索框和提示词列表的选择器。 -->
9. 在选择器里点击刚才那条提示词。正文进入输入框，不会自动发送。

**结果：** 提示词库里有了第一条提示词；输入框草稿里是它的正文，补充你的问题后可以自己发送。
