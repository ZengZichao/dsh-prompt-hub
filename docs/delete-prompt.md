# 删除提示词

从库里移除一条不再需要的提示词。删除会同步给 AI，因为面板和 AI 读写同一份库。

1. 打开 **提示词中心**，找到目标提示词。
2. 点击 **更多操作**（⋯），选择 **删除**。
3. 如果开启了删除确认，在“删除提示词「标题」”对话框里点击 **删除**。
4. 面板提示“已删除「标题」”。
5. 删错了就立刻点提示条上的 **撤销**。

**结果：** 该提示词从列表消失，面板顶部的条数减一。

> 提示：删除后先留意提示条。带 **撤销** 的删除提示可能紧接着被“已保存”提示替换，撤销入口也会随之消失；这时只能从自动备份手动恢复，见 [理解提示词库的存储与备份](storage-and-backups.md)。

> 提示：在 **设置** 里取消勾选 **删除前确认**，删除会跳过确认框直接执行。
