# 搜索和筛选提示词

在库里快速定位一条提示词。搜索匹配标题、标签和正文，不区分大小写。

1. 打开 **提示词中心**。
2. 在 **搜索提示词** 框里输入关键词，列表随输入过滤。
3. 需要按分类缩小范围时，在左侧 **分类** 栏点一个分类，或点 **未分类**。
4. 需要按标签过滤时，在列表上方的 **标签** 下拉里选一个标签。
5. 清空搜索框，或把标签切回 **全部标签**，恢复完整列表。

**结果：** 列表只剩符合条件的提示词；顶部的条数仍是整个库的总数，不是筛选结果数。

> 提示：搜索和标签过滤都在当前分类范围内生效。先选 **全部** 再搜索，才不会漏掉其他分类的条目。

> 提示：**标签** 下拉只列出当前分类里出现过的标签，并带出现次数。

> 提示：筛选没有结果时，列表显示“没有匹配的提示词”；清空搜索或切回 **全部标签** 即可恢复。

> 提示：列表一次最多显示 200 条。底部出现“另有 N 条未显示”时，用搜索或分类继续缩小范围。
