# 编辑提示词

修改已有提示词的标题、分类、标签或正文。先打开 **提示词中心**，并选中它所在的分类（或 **全部**）。

1. 在列表里找到目标提示词。
2. 点击行内的 **编辑**。
3. 按需修改 **标题**、**分类**、**标签**、**内容**。
4. 点击 **保存**。

**结果：** 面板提示“已保存”，修改立即生效。未置顶的提示词会按最近更新排到列表前面；置顶的仍在最前。

> 提示：点 **取消** 会直接返回列表，不保存改动，也不会二次确认。

> 提示：标签的增删和新建时一致：Enter 或逗号添加，点标签上的 × 删除；最多 20 个标签。
