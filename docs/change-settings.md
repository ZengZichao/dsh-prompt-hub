# 修改提示词中心设置

调整插入方式、选择器显示条数和删除确认。设置只影响当前浏览器，立即生效并保存在本机。

<!-- 截图位：设置对话框，含插入方式、显示条数、删除前确认三项。alt：设置对话框里从上到下是插入方式下拉、显示条数下拉和删除前确认复选框，底部是关闭按钮。 -->

1. 打开 **提示词中心**。
2. 点击标题右侧的 **设置** 按钮（滑杆图标）。
3. 在 **设置** 对话框里调整：
   - **插入方式**：**追加** 或 **替换**。
   - **显示条数**：**10**、**20** 或 **50**，控制输入框选择器一次显示多少条。
   - **删除前确认**：勾选后，删除提示词或分类会先弹确认框。
4. 点击 **关闭**。

**结果：** 改动一经选择立即保存，下次打开面板或选择器时继续生效。

> 提示：设置保存在浏览器的 `localStorage`，不随提示词库同步；换浏览器或换设备要重新设置。

> 提示：**插入方式** 只影响从输入框插入，不影响面板里编辑提示词。

> 提示：**显示条数** 只管输入框选择器；面板列表仍最多渲染 200 条。
