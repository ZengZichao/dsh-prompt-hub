# 导入和导出提示词库

把整个提示词库导出成 JSON 备份或迁移到另一台机器，或把别处的 JSON 合并进来。

## 导出或复制 JSON

1. 打开 **提示词中心**。
2. 点击左侧栏底部的 **导入导出**。
3. 在 **导入与导出** 对话框里选择：
   - **导出 JSON**：下载 `prompt-hub.json` 到浏览器下载目录。
   - **复制 JSON**：把同一份内容复制到剪贴板。
4. 点击 **关闭**。

## 导入 JSON

1. 打开 **导入导出**，点击 **导入 JSON**。
2. 在文件选择器里选一个 `.json` 文件。
3. 在 **导入提示词** 对话框确认统计：“分类 N 个，新增 X，已存在 Y”与“提示词 N 条，新增 X，已存在 Y”。
4. 选择导入方式：
   - **合并**（默认）：保留现有条目，只添加库里没有的条目。
   - **替换现有库**：用文件内容覆盖当前库，不可恢复。
5. 点击 **导入**。

**结果：** 面板提示“导入完成”，列表和分类按选定的方式更新。

> 提示：判断“已存在”看的是条目 id，不是标题。两条标题相同、id 不同的提示词会同时存在。

> 提示：**替换现有库** 在面板里不能撤销。导入前先 **导出 JSON** 留一份当前库。

> 提示：导入文件必须是 JSON 对象（`{ … }`）。不是合法 JSON 或不是对象时，面板提示“导入失败：……”。`categories` 或 `prompts` 不是数组时：合并模式会当作空列表处理，替换模式会以“保存失败：……”结束。数量和正文字符超限时同样是保存失败。
