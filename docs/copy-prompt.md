# 复制提示词

dsh-prompt-hub 里的“复制”有两种：在库里生成一条独立副本，或把正文复制到剪贴板。

## 创建提示词副本

1. 打开 **提示词中心**，在列表里找到目标提示词。
2. 点击行尾的 **更多操作**（⋯）。
3. 点击 **创建副本**。
4. 在列表顶部找到新副本，按需 **编辑** 后 **保存**。

副本的标题自动加“（副本）”，正文、分类和标签照搬，置顶状态不继承。

**结果：** 新副本出现在列表顶部（置顶条目仍更前），可以像普通提示词一样编辑、插入或删除。

## 复制正文到剪贴板

1. 点击目标提示词的 **更多操作**。
2. 点击 **复制内容**。
3. 面板提示“已复制”。

**结果：** 正文已写入剪贴板，可以粘贴到其他输入框或文档里。

> 提示：浏览器拒绝剪贴板写入时不会有任何提示。遇到这种情况，检查 Harness 的剪贴板权限，或改用 **导入导出** 里的 **导出 JSON**。
