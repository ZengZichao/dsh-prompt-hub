# 新建提示词

把一条新提示词存进库里，并归到合适的分类、打上标签。开始前先打开侧栏的 **提示词中心**。

<!-- 截图位：提示词中心的编辑页，含标题、分类、标签、内容四个字段和保存按钮。alt：新建提示词编辑页，标题输入框在上，分类下拉、标签输入框和正文文本域依次排列，右上角是保存和取消。 -->

1. 点击面板上方的 **新建提示词**。
2. 在 **标题** 里填写名称，最多 200 个字符。
3. 在 **分类** 下拉里选择归属；不归类就选 **未分类**。
   > 提示：在 **全部** 视图下新建时，默认归入分类列表里的第一个分类；在 **未分类** 视图下新建也一样。想归到未分类，需要在第 3 步手动选择。
4. 在 **标签** 输入框里输入短标签，按 Enter 或逗号确认；点标签上的 × 删除标签。
   > 提示：最多 20 个标签，每个标签最多 40 个字符；只有大小写不同的标签会被视为重复。
5. 在 **内容** 里写正文。要留待插入时替换的词，写成 `{{名称}}`。
6. 点击 **保存**。

**结果：** 面板提示“已保存”，提示词出现在列表顶部（置顶的条目仍排在更前），左侧对应分类的数量加一。

> 提示：标题或内容为空时，面板会提示“请填写标题”或“请填写内容”，并留在编辑页。

> 提示：正文超过 100,000 个字符时保存会失败，面板提示“保存失败：……”。
