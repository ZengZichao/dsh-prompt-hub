# 管理分类

新建、重命名、排序或删除分类。分类决定左侧栏的分组，也决定新建提示词的默认归属。

<!-- 截图位：管理分类对话框，含每行分类名、数量以及上移、下移、重命名、删除按钮。alt：管理分类列表，每行右侧依次是上移、下移、重命名、删除，底部是新建分类和关闭。 -->

1. 打开 **提示词中心**。
2. 在左侧 **分类** 栏点击 **管理**。
3. 在 **管理分类** 对话框里按需操作：
   - 点击 **新建分类**，在 **分类名称** 里输入名称，点击 **保存**。
   - 在某一行点击 **重命名**，改完名称后点击 **保存**。
   - 点击 **上移** 或 **下移** 调整顺序。第一行的 **上移** 和最后一行的 **下移** 不可用。
   - 点击 **删除** 删除该分类。
4. 点击 **关闭** 退出对话框。

**结果：** 每次操作后提示“已保存”，左侧分类栏按新顺序显示；分类名后的数字是该分类的提示词数量。

> 提示：删除分类会弹出确认框“删除分类「名称」”，其中的提示词会移到 **未分类**，不会跟着删除。删除后提示条上会提供 **撤销**，看到就立即点；它可能被随后的“已保存”提示替换。

> 提示：新建、重命名和删除会先关闭 **管理分类** 对话框；要继续管理其他分类，再次点击 **管理**。
